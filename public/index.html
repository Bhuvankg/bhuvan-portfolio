Frequently Asked Questions

Common Questions About GradeAI

How does the AI grade short answers and descriptive responses?
GradeAI uses advanced natural language processing to evaluate responses semantically against teacher-defined reference answers and rubrics. It assesses conceptual comprehension, terminology coverage, and logical structure rather than requiring verbatim word-for-word repetition. Partial credit is awarded according to weighted rubric criteria.
Does the system automatically publish grades without teacher review?
Never without explicit educator authorization. AI-generated scores remain recommendations in a review queue. Instructors can modify any mark, amend the constructive comments, and must click "Approve & Publish Grade" before students receive their finalized results.
How is plagiarism detected between students?
Submissions undergo text normalization and 3-word n-gram shingle indexing. Pairwise comparisons compute Jaccard similarities and extract continuous overlapping clauses. When textual overlap crosses the configured threshold, a report is generated with side-by-side highlighted passages for instructor review.
What happens if the external AI API key is not configured?
GradeAI includes a deterministic, zero-dependency built-in Semantic Evaluation Engine that executes locally. It tokenizes, checks required conceptual keywords, computes shingle overlap against reference answers, and generates scores and feedback with 100% reliability out-of-the-box.
